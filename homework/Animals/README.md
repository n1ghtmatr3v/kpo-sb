# ERP-система Московского зоопарка

## Описание проекта
Консольное приложение для автоматизации учета животных и инвентаря Московского зоопарка. Система разработана в соответствии с требованиями Высшей школы экономики и обеспечивает эффективное выполнение повседневных задач зоопарка.

## Функциональные возможности

### Учет животных
- Прием новых животных на баланс зоопарка
- Обязательная проверка здоровья ветеринарной клиникой перед принятием
- Автоматическая инвентаризация животных с присвоением номеров
- Учет потребления еды (кг/сутки) для каждого животного

### Контактный зоопарк
- Формирование списков животных для интерактивного взаимодействия с посетителями
- Отбор травоядных животных с уровнем доброты выше 5 баллов
- Исключение хищников и недостаточно добрых травоядных

### Отчетность
- Отчет по количеству животных в зоопарке
- Расчет общего потребления еды всеми животными
- Инвентарный учет с выводом наименований и номеров
- Статистика по контактным животным

## Архитектурные решения

### Доменная модель
Система построена на основе SOLID принципов с использованием DI-контейнера Spring:

**Интерфейсы:**
- `IAlive` - для живых сущностей (свойство Food)
- `IInventory` - для инвентаризуемых объектов (свойство Number)

**Иерархия животных:**
- `Animal` - базовый класс (реализует IAlive, IInventory)
- `Herbo` - травоядные животные (доброта)
- `Predator` - хищные животные
- Конкретные классы: `Monkey`, `Rabbit`, `Tiger`, `Wolf`

**Иерархия вещей:**
- `Thing` - базовый класс (реализует IInventory)
- `Table`, `Computer` - конкретные вещи

### Принципы проектирования
- **SRP** - каждый класс имеет четкую зону ответственности
- **OCP** - система легко расширяется новыми типами животных и вещей
- **LSP** - наследники полноценно заменяют базовые классы
- **ISP** - интерфейсы разделены по функциональности
- **DIP** - зависимости управляются через Spring DI контейнер
